# 💊 E-Pharmacy Client

## 🔗 [Live Demo](TBD) | 🎨 [Figma Design](https://www.figma.com/file/qrKzOBVqM6zOZNFkTOpEO0/E-PHARMACY-(clients)?type=design&node-id=0-1&mode=design&t=O9kTuPJAS2bjEuwM-0)

**E-Pharmacy** is a modern, responsive web application designed for ordering medications online, exploring local medicine stores, managing a shopping cart, and tracking health-related product details seamlessly.

## 🚀 Key Features

* **User Authentication & Authorization** — Secure registration, login, token management, and automatic access control for private routes.
* **Responsive Layout** — Fluid mobile layout starting from 375px, scaling smoothly up to tablet (768px+) and desktop (1440px+) viewports.
* **Interactive Home Page** — Features promo banners with discounts, a list of nearest medicine stores, and user reviews fetched from the backend.
* **Medicine Stores Directory** — Browse medicine stores with status indicators (*Open* / *Close*), ratings, addresses, and contact numbers.
* **Advanced Medicine Catalog** — Filter products by category, search by name, and navigate easily using server-side pagination.
* **Product Details & Reviews** — View comprehensive product descriptions, usage guidelines, ratings, and customer reviews with built-in tab switching.
* **Shopping Cart & Checkout** — Manage product quantities, review pricing, enter shipping details, select payment methods (*Cash On Delivery*, *Bank*), and place orders.
* **Form Validation & Notifications** — Clean form handling powered by **React Hook Form** and instant feedback via **react-hot-toast**.

## 🛠 Tech Stack

* **Framework:** React / Next.js
* **Language:** TypeScript
* **State Management:** Zustand / Redux Toolkit
* **Data Fetching & Caching:** TanStack React Query
* **API Client:** Axios
* **Form Validation:** React Hook Form
* **Styling:** CSS Modules, Modern Normalize
* **UI Libraries:** MUI (Date Pickers) / Blueprint.js
* **Icons:** SVG Sprites & React Icons
* **Deployment:** Vercel
